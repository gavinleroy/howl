# Howl

An [MLsub](https://dl.acm.org/doi/10.1145/3093333.3009882) inspired Lispy ML.

It's main, and only use, is for [my blog](https://gavinleroy.com/writings/posts/errors-diagnostics-interaction/) on Parametric Error Rendering.

Some pointers:

- The Howl language is defined in `src/lang`
- The diagnostic *renderers* are in `web/render`
- The diagnostic *viewers* are in `web/src`

## Any future plans?

I will also experiment with typed macros and macro debugging.
